# Sizes

Status: generated by `cargo xtask sizes --from DIR` from `sizes.json`, held by `cargo xtask check-sizes`. Do not edit by hand.

What every artefact a release ships weighs, in bytes. **Gzipped** is what a consumer downloads, so it is the column a decision reads; an artefact that is already compressed (an archive, a wheel, a jar) has only its own size. The figures are recorded from one CI run, since every platform builds on its own runner, and verify fails when a run moves any of them more than 2% from the record (`03-design/generated-pages.md` §1).

# Documentation style

Status: `draft`, 2026-09-04 (Q12 confirms the spelling convention).

1. **Every page starts with its status** (`research`, `draft`, `proposed`,
   `accepted`, `planned`, `generated`) and the date it was last checked.
2. **Numbers come from somewhere.** A number in prose is either read from
   a file that gates it, generated by a tool, or cited to a source with a
   date. If it is from memory, mark it **verify** and add it to the page's
   closing checklist.
3. **One source of truth.** A fact lives in one page; other pages link to
   it. A claim repeated in two places is the one that goes stale.
4. **British spelling** (`behaviour`, `optimise`, `licence` the noun).
   Astrological terms use the SDK's canonical key spelling in code and the
   locale pack's spelling in prose.
5. **Questions are never buried.** An open question goes to `QUESTIONS.md`
   with options and a recommendation; the page links to it by number.
6. **Tables for parallel facts, prose for argument.** Feature pages use the
   shared column set so the catalogue can be derived.
7. **Generated pages are never edited by hand**; their header names the
   generator.
8. **Comments in code** (once there is code) explain why and name the
   measurement, the alternative rejected and the defect that motivated the
   code; a comment that restates the code is removed.
9. **No attribution to tools or assistants** in any document, commit or
   artefact.
10. **Plain words.** Say what a thing is before what it is called; expand a
    Sanskrit term the first time it appears in a page.

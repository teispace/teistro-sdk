# The Teimeris ephemeris, as a Teistro adapter

Two things, and a consumer needs both: the **descriptor** an `ephemeris`
chain takes, and a **typed façade** over the engine's own operations.

The SDK computes with whatever ephemeris it is given. In most cases that
should be a real engine (Teimeris here), and the SDK's own built-in is
the fallback rather than the intended path (ADR-0029).

```java
import com.teispace.teistro.*;
import com.teispace.teistro.teimeris.Teimeris;

Teistro sdk = Teistro.open();
try (Context sky = sdk.context(ContextOptions.builder()
        .ephemeris(Teimeris.builder().dataDir("./ephe").build(),
                   EphemerisChoice.of(Ephemeris.BUILTIN))
        .build())) {
    Teimeris.engine(sky.ephemeris()).tmBodyName(0);  // "Sun"
}
```

The module is `com.teispace.teistro.teimeris`, which requires
`com.teispace.teistro` transitively.

## The descriptor

It names the engine, not a file. The platform binary is this package's to
find, and `build()` fails when it cannot, naming every place it looked, in
the line that names the engine rather than when a chart is cast. It looks
at `-Dteistro.teimeris.adapter`, then `TEISTRO_TEIMERIS_ADAPTER`, then the
adapter's own release and debug builds from the working directory upward;
`Builder.path` names it outright.

A chain is ordered and explicit: the entries are tried in order, and a
context asked for an engine and given the built-in without being told is
the silence this refuses.

## The typed façade

`TeimerisEngine` is generated by `cargo xtask engine` from the engine's own
description, as the Node, Dart and Python façades are; what it can marshal
is a measurement, published in
`docs/03-design/engine-passthrough-measured.md`. A method hands back the
one value its function answers with, as itself; the few that answer with
more get a record nested in the class, as each struct the engine declares
does, read with `fromJson` and written with `toJson`. A whole number is a
`long`, because the engine's integers include `uint32_t` flag sets and
`int64_t`.

Every operation is also reachable untyped, through the SDK alone, as
`sky.ephemeris().call(name, arguments)`. The façade gives the names back;
it does not gate the route.

`cargo xtask check-java` compiles the module and
[`typecheck/Consumer.java`](typecheck/Consumer.java), this page's shape
read all the way down, against the binding at its floor with every lint an
error.

# `teistro-prashna`

Prashna as the Teistro SDK reads it: a chart cast for the moment a
question is asked, read as the texts that teach it print the rules
(`docs/03-design/prashna.md`).

- ***Shatpanchashika*** (ed. V. Subrahmanya Sastri, 1941), read on the
  page images:
  - I.3, I.4 and II.2: whether the matter succeeds, as three outcomes
    over stated clauses;
  - II.1–2: whether it stays as it is or changes;
  - II.14–15, V.5 and II.17: when;
  - VII.7–8: whom an unspoken question is about;
  - I.7: the class of the thing thought of.
- The baseline engine's timing rule, which no text read gives, is the
  `BASELINE` value of the timing rule, and is marked unsourced.

The kernel reads no ephemeris. It takes the query chart's placements,
navāṁśas and Shadbala totals as a `PrashnaSky`, which the SDK fills from
the chart the caller cast.

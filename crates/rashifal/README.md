# teistro-rashifal

One period of the sky read for each of the twelve signs, each taken as a
reader's janma rāśi: Phaladeepika ch. 26's gochar from that sign,
Saturn's standing through the Sade Sati kernel, and the period's
ingresses and stations counted from it. The baseline engine's 0–100
score is `baseline::baseline_score`, `BASELINE` and unsourced, reached
only when asked.

Design: `docs/03-design/rashifal.md`.

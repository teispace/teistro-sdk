# `teistro-kp`

Krishnamurti Paddhati (`03-design/kp.md`): every nakshatra divided among
the nine Vimshottari lords in proportion to their years, and each part
divided again the same way, as the KP Readers teach it.

What is built is the arithmetic every later part reads: the sign, star,
sub and sub-sub lords of any longitude, and any deeper level, found
**exactly** in integer nanoarcseconds, with the arc each level spans so a
caller can see how near a boundary a position stands; and the 249 horary
numbers, the 243 subs with the six that a sign boundary cuts in two,
generated by that rule and held to the rows the Reader prints.

Reached from `intl.has` on the surface; [the surface](/docs/surface) says how each binding spells a path.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `key` | `const char *` | a string read | — |
| `out_has` | `uint8_t *` | receives a number | — |

## What it hands back

`has`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `key` a NUL-terminated string; `out_has` valid for a write.

Declared in `crates/ffi/src/intl.rs`.

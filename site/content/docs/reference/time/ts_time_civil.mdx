Reached from `time.civil_of` on the surface; [the surface](/docs/surface) says how each binding spells a path.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `jd_utc` | `double` | a value | Unit `jd`. |
| `zone` | `const ts_zone_spec *` | a struct read | — |
| `calendar` | `uint16_t` | a value | One of `ts_calendar`. |
| `out_civil` | `ts_civil_date_time *` | a struct written | — |
| `out_resolution` | `ts_zone_resolution *` | a struct written | — |

## What it hands back

`civil` and `resolution`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `zone` valid for a read; `out_civil` and `out_resolution` valid for reads of their `struct_size` and writes.

Declared in `crates/ffi/src/time.rs`.

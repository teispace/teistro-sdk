## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `jd_ut1` | `double` | a value | Unit `jd`. |
| `out_delta_t` | `ts_delta_t *` | a struct written | — |

## What it hands back

`delta_t`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `out_delta_t` valid for a read of its `struct_size` and a write.

Declared in `crates/ffi/src/time.rs`.

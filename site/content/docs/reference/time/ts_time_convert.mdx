Converts an instant between UT1, TT and UTC under the context's Delta T model, reporting what was applied. A model that cannot answer for the instant is `OUT_OF_RANGE`.

<Tabs items={['C', 'Node', 'Dart']}>
<Tab value="C">

```c
ts_status ts_time_convert(const ts_context * context, double jd, uint32_t from, uint32_t to, ts_time_conversion * out_conversion);
```

</Tab>
<Tab value="Node">

```js
context.time_convert(…)
```

The addon's generated layer; `@teistro/sdk` wraps it.

</Tab>
<Tab value="Dart">

```dart
context.timeConvert(…)
```

The generated `TeistroLibrary`; `package:teistro` wraps it.

</Tab>
</Tabs>

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `jd` | `double` | a value | Unit `jd`. |
| `from` | `uint32_t` | a value | One of `ts_scale`. |
| `to` | `uint32_t` | a value | One of `ts_scale`. |
| `out_conversion` | `ts_time_conversion *` | a struct written | — |

## What it hands back

`conversion`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `out_conversion` valid for a read of its `struct_size` and a write.

Declared in `crates/ffi/src/time.rs`.

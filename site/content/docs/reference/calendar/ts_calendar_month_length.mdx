## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `calendar` | `uint16_t` | a value | One of `ts_calendar`. |
| `year` | `int32_t` | a value | — |
| `month` | `uint8_t` | a value | — |
| `out_length` | `uint8_t *` | receives a number | — |

## What it hands back

`length`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `out_length` valid for a write.

Declared in `crates/ffi/src/calendar.rs`.

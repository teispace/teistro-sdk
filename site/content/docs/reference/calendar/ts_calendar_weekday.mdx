Reached from `calendar.weekday_of` on the surface; [the surface](/docs/surface) says how each binding spells a path.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `date` | `const ts_calendar_date *` | a struct read | — |
| `out_weekday` | `uint8_t *` | receives a number | — |

## What it hands back

`weekday`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `date` valid for a read; `out_weekday` valid for a write.

Declared in `crates/ffi/src/calendar.rs`.

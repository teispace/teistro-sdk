The fixed day a Julian day falls in, and, when `out_fraction` is not null, the fraction of that day elapsed since its midnight.

```c
int64_t ts_calendar_fixed_of_jd(double jd, double * out_fraction);
```

No operation of a context calls this by name. A binding calls it itself, opening the library, freeing what the library handed back or reading an error, or offers it outside a context, as the library's version and the fixed-day arithmetic are.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `jd` | `double` | a value | — |
| `out_fraction` | `double *` | receives a number | — |

## What it hands back

`value` and `fraction`.

## Safety

`out_fraction` must be null or valid for a write.

Declared in `crates/ffi/src/calendar.rs`.

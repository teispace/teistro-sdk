Reached from `calendar.date_of` on the surface; [the surface](/docs/surface) says how each binding spells a path.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `calendar` | `uint16_t` | a value | One of `ts_calendar`. |
| `fixed` | `int64_t` | a value | — |
| `out_date` | `ts_calendar_date *` | a struct written | — |

## What it hands back

`date`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `out_date` valid for a read of its `struct_size` and a write.

Declared in `crates/ffi/src/calendar.rs`.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `date` | `const ts_calendar_date *` | a struct read | — |
| `out_fixed` | `int64_t *` | receives a number | — |

## What it hands back

`fixed`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `date` valid for a read; `out_fixed` valid for a write.

Declared in `crates/ffi/src/calendar.rs`.

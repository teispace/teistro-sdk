title: Enums
description: Every enum of the C ABI, with the value each member carries.
---

An enum crosses the boundary as its integer. The catalogue's kinds keep their values forever: a member's number is part of the ABI, and a stored result read back years later means what it meant when it was written.

Adapters map them to their own numbering; a body an adapter cannot compute is reported per cell, never guessed.

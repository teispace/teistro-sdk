Every instant in a range at which something changes, as sealed JSON (`03-design/change-points.md`). `request_json` is the record: `first`, optional `last`, `calendar`, `latitudeDeg`, `longitudeDeg`, `altitudeM`, `utcOffsetSeconds` or `zone`, and optional `kinds`.

Reached from `almanac.changes` on the surface; [the surface](/docs/surface) says how each binding spells a path.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `request_json` | `const char *` | a string read | — |
| `out_json` | `ts_string *` | receives a string | — |

## What it hands back

`json`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `request_json` NUL-terminated; `out_json` valid for a write.

Declared in `crates/ffi/src/panchanga.rs`.

What a month grid prints of every date in a range, as sealed JSON (`03-design/month-cells.md`). `request_json` is the record: `first`, optional `last`, `calendar`, `latitudeDeg`, `longitudeDeg`, `altitudeM`, `utcOffsetSeconds` or `zone`, and optional `festivals`, a festival request. The answer is `{cells, observances}`: each cell `{date, vara, sunrise, nextSunrise, normal, tithi, paksha, month, ends, kind, festivals}`, `observances` only when festivals were asked.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `request_json` | `const char *` | a string read | — |
| `out_json` | `ts_string *` | receives a string | — |

## What it hands back

`json`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `request_json` NUL-terminated; `out_json` valid for a write.

Every rule of a festival pack with what it is (`03-design/festival-metadata.md` §3), as canonical JSON `{pack, rules}`: each row `{key, form, source, meta, unsourced}`, `form` how its day is found (`LUNAR`, `EKADASHI`, `FOLLOWING`, `DATED`, `PUBLISHED`), `meta` its kind, tradition, communities and regions, `unsourced` the fields no source gives, and a published row's `subjectTo` and `lastYear`.

`request_json` is `{"pack"}`, a pack the SDK ships. Nothing is reckoned, so a context without an ephemeris answers. A key it does not read or a pack it does not ship is `INVALID_ARG`, named under `pack`.

```c
ts_status ts_almanac_festival_pack(const ts_context * context, const char * request_json, ts_string * out_json);
```

## Parameters

| name | type | role | what it carries |

## What it hands back

`json`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `request_json` NUL-terminated; `out_json` valid for a write.

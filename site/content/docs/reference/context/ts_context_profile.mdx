## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `out_profile` | `ts_str *` | receives a lent string | — |

## What it hands back

`profile`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `out_profile` valid for a write.

Declared in `crates/ffi/src/context.rs`.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `out_hash` | `ts_hash *` | a struct written | — |

## What it hands back

`hash`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `out_hash` valid for a write.

Declared in `crates/ffi/src/context.rs`.

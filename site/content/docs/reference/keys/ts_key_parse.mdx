Resolves a full key (`graha.SUN`, an alias, or a former key) to its packed id. An unknown key is `UNSUPPORTED` with the nearest known key as the hint in the context's last error.

<Tabs items={['C', 'Node', 'Dart']}>
<Tab value="C">

```c
ts_status ts_key_parse(const ts_context * context, const char * key, uint32_t * out_id);
```

</Tab>
<Tab value="Node">

```js
context.key_parse(…)
```

The addon's generated layer; `@teistro/sdk` wraps it.

</Tab>
<Tab value="Dart">

```dart
context.keyParse(…)
```

The generated `TeistroLibrary`; `package:teistro` wraps it.

</Tab>
</Tabs>

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `key` | `const char *` | a string read | — |
| `out_id` | `uint32_t *` | receives a number | — |

## What it hands back

`id`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `key` a NUL-terminated string; `out_id` valid for a write.

Declared in `crates/ffi/src/keys.rs`.

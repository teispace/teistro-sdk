The navatara chakra of a birth star: the 27 stars in the order the count from the birth star reaches them, each `{"nakshatra", "count", "tara", "cycle", "special"}`, `cycle` the round of nine (1 janma, 2 anujanma, 3 trijanma) and `special` the star *Muhurta Chintamani* names at that count (`JANMA`, `KARMA`, `SANGHATIKA`, `SAMUDAYA`, `VAINASHIKA`, `MANASA`) or null (C1053).

`request_json` is `{"birth"}`, a nakshatra key. A key the record does not read, or a star that is not a nakshatra key, is `INVALID_ARG`, named under `navatara`.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `request_json` | `const char *` | a string read | — |
| `out_json` | `ts_string *` | receives a string | — |

## What it hands back

`json`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `request_json` NUL-terminated; `out_json` valid for a write.

Declared in `crates/ffi/src/navatara.rs`.

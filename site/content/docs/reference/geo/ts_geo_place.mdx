A place by its id from the context's geo provider, answered as canonical JSON `{asked, place, moved}`: `place` as `ts_geo_list` answers one, with its id line (`line`), IANA zone (`zone`), population and landmark `class`, null for an id the provider does not know or holds as removed; `moved` true when the id asked was retired and `place` is the one that replaced it, under its own id, which a caller stores instead (SR-164).

`request_json` is `{"id", "lang"}`: an id an answer gave, and a BCP 47 tag to name the place in. An empty id or a malformed tag is `INVALID_ARG` on `id` or `lang`.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `request_json` | `const char *` | a string read | — |
| `out_json` | `ts_string *` | receives a string | — |

## What it hands back

`json`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `request_json` NUL-terminated; `out_json` valid for a write.

Frees a string the library allocated and zeroes the descriptor; null or an empty string is ignored.

```c
void ts_string_free(ts_string * string);
```

No operation of a context calls this by name. A binding calls it itself, opening the library, freeing what the library handed back or reading an error, or offers it outside a context, as the library's version and the fixed-day arithmetic are.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `string` | `ts_string *` | the string being freed | — |

## Safety

`string` must be null or a descriptor written by this library that is not used again.

Declared in `crates/ffi/src/string.rs`.

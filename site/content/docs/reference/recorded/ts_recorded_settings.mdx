Translates a stored baseline settings snapshot and answers with the translation as canonical JSON: the natal context's profile and patch, the KP context's, the ephemeris the natal chain needs at its front (`SURYA_SIDDHANTA` or `null`), the locale and every field read and set aside as a note (`03-design/compat-shim.md` §4.1). The context records a refusal; the translation reads none of its settings.

`snapshot_json` is one object of the baseline engine's own field names, `{"ayanamsaId": 1, "houseSystem": "whole-sign", ...}`, a nested record under its field. A snapshot that is not an object is `INVALID_ARG` on `snapshot`; a field or value the table does not know, `INVALID_ARG` on `snapshot.<field>`; a value the SDK decided not to carry, such as the Surya bija, `UNSUPPORTED` on `snapshot.<field>` with the crux as its hint.

```c
ts_status ts_recorded_settings(const ts_context * context, const char * snapshot_json, ts_string * out_json);
```

Reached from `(root).recorded_settings` on the surface; [the surface](/docs/surface) says how each binding spells a path.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `snapshot_json` | `const char *` | a string read | — |
| `out_json` | `ts_string *` | receives a string | — |

## What it hands back

`json`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `snapshot_json` NUL-terminated; `out_json` valid for a write.

Declared in `crates/ffi/src/recorded.rs`.

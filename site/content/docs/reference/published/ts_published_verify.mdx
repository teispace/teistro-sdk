title: ts_published_verify
description: "Verifies a signed pack and answers with its published set as canonical JSON."

Verifies a signed pack and answers with its published set as canonical JSON. `pack` is the set's exact bytes, `signature` the publisher's detached Ed25519 signature over them (64 bytes) and `key` the publisher's public key (32 bytes), which the caller fixes at its own build: the library embeds none. A set whose `version` is under `at_least`, the newest the caller has applied, is refused, so a replayed pack cannot roll a correction back; 0 takes any.

A key that is no curve point is `INVALID_ARG` on `key`; a signature that is not 64 bytes or does not verify, `INVALID_ARG` on `signature`; bytes that are not a set, `INVALID_ARG` on the field that is wrong; an older version, `INVALID_ARG` on `version`. A build without `signed-packs` answers `CAPABILITY`.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `pack` | `const uint8_t *` | bytes read | — |
| `pack_len` | `size_t` | a length | — |
| `signature` | `const uint8_t *` | bytes read | — |
| `signature_len` | `size_t` | a length | — |
| `key` | `const uint8_t *` | bytes read | — |
| `key_len` | `size_t` | a length | — |
| `at_least` | `uint32_t` | a value | — |
| `out_json` | `ts_string *` | receives a string | — |

## What it hands back

`json`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `pack`, `signature` and `key` valid for their lengths' reads; `out_json` valid for a write.

Declared in `crates/ffi/src/published.rs`.

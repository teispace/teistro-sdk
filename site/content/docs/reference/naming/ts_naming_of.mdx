The names a birth gives, of *Dharmasindhu*'s four that the SDK computes (C773): the birth pada's syllable with its initials, and the star's deity, whose name the Śāṅkhāyanas give.

`request_json` is `{"birth", "rules"}`. The answer is `Names`. A pada outside 1 to 4 is `INVALID_ARG`, named `naming.birth.pada`.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `request_json` | `const char *` | a string read | — |
| `out_json` | `ts_string *` | receives a string | — |

## What it hands back

`json`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `request_json` NUL-terminated; `out_json` valid for a write.

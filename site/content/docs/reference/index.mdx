The SDK has one boundary: a C ABI of 39 entry points over 25 structs and 75 enums. Every binding's mechanical layer is generated from a description of it, `idl/api.json`, which is extracted from the boundary crates' own source and gated by `cargo xtask check-ffi`. These pages are generated from that same description, so a page cannot describe an entry point the library does not have.

ABI version **1**, SDK **0.0.0**, symbol prefix `ts_`.

## Where each entry point lives

| entry point | what it does |
|---|---|
| [`ts_abi_version`](library/ts_abi_version) | The ABI version this library implements. |
| [`ts_sdk_version`](library/ts_sdk_version) | The SDK version as a static NUL-terminated string (`0.0.0`). |
| [`ts_catalogue_version`](library/ts_catalogue_version) | The catalogue schema version every result's provenance stamps. |
| [`ts_default_profile`](library/ts_default_profile) | The profile a context uses when its options name none, as a static NUL-terminated string. |
| [`ts_build_info`](library/ts_build_info) | What this build is, as a static NUL-terminated JSON object: the SDK version, the ABI and catalogue versions, the commit and whether its tree was clean, the profile, the target, whether debug assertions and optimisation are on, the sanitizer if any, and the compiler. |
| [`ts_status_message`](library/ts_status_message) | A static NUL-terminated English phrase for a status code; `unknown status` for a code this build does not know. |

|---|---|

## The rules every entry point follows

- Every struct begins with `struct_size`, which the caller sets to `sizeof` before the call: a library built from a newer description can tell how much of the struct the caller knows about.
- A call that can fail returns a status; `ts_status_message` reports what went wrong, with the field and a hint when it has them.
- The library frees what the library allocated. A result blob and an owned string are handed back with the call that frees them; a lent string is valid until the next call on the same context.
- A panic never crosses the boundary: it becomes an internal status.

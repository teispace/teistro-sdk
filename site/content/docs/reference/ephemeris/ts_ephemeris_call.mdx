Calls one of the engine's own operations by the name its manifest gives.

`arguments_json` is a JSON object keyed by the parameter names the manifest names, holding the ones it marks as a caller's to supply. The answer is the engine's own JSON, unread by this library.

`CAPABILITY` when the context has no ephemeris, `UNSUPPORTED` when the engine describes nothing of its own or names no such operation, and `PROVIDER` when the engine itself refuses.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `function` | `const char *` | a string read | — |
| `arguments_json` | `const char *` | a string read | — |
| `out_json` | `ts_string *` | receives a string | — |

## What it hands back

`json`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `function` and `arguments_json` must be NUL-terminated; `out_json` valid for a write.

Declared in `crates/ffi/src/ephemeris.rs`.

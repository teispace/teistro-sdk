Writes the SDK's canonical frame: apparent geocentric ecliptic of date, tropical, which both licensed engines return by default and every chart module consumes. Set `struct_size` before the call.

Reached from `frame.canonical` on the surface; [the surface](/docs/surface) says how each binding spells a path.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `out_frame` | `ts_frame *` | a struct written | — |

## What it hands back

`frame`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`out_frame` must be valid for a read of its `struct_size` and a write.

Declared in `crates/ffi/src/frame.rs`.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `frame` | `const ts_frame *` | a struct read | — |
| `out_bits` | `uint32_t *` | receives a number | — |

## What it hands back

`bits`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`frame` must be valid for a read of its `struct_size`; `out_bits` for a write.

Declared in `crates/ffi/src/frame.rs`.

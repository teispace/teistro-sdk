Reached from `keys.name` on the surface; [the surface](/docs/surface) says how each binding spells a path.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `id` | `uint32_t` | a value | — |
| `out_key` | `ts_str *` | receives a lent string | — |

## What it hands back

`key`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `out_key` valid for a write.

Declared in `crates/ffi/src/key.rs`.

Resolves a full key (`graha.SUN`, an alias, a former key, or a member the context registered, `chart_layout.ACME_KERALA`) to its packed id. An unknown key is `UNSUPPORTED` with the nearest known key as the hint in the context's last error.

Reached from `keys.id` on the surface; [the surface](/docs/surface) says how each binding spells a path.

## Parameters

| name | type | role | what it carries |
|---|---|---|---|
| `context` | `const ts_context *` | the handle | — |
| `key` | `const char *` | a string read | — |
| `out_id` | `uint32_t *` | receives a number | — |

## What it hands back

`id`. The call returns a status; a status other than `TS_STATUS_OK` means nothing was written.

## Safety

`context` must be a live handle; `key` a NUL-terminated string; `out_id` valid for a write.

Declared in `crates/ffi/src/key.rs`.
